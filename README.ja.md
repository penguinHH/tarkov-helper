# Tarkov Helper

[简体中文](README.md) | [English](README.en.md) | **日本語**

Escape from Tarkov（タルコフ）のデスクトップ補助ツールです。インタラクティブマップ、アイテム価格、タスク検索、BTR ルート予測を備えています。Electron + Vue 3 + Leaflet 製で、ゲームデータは [tarkov.dev](https://tarkov.dev) のオープンデータを使用しています。

## ダウンロード

[Releases](https://github.com/penguinHH/tarkov-helper/releases/latest) から最新版をダウンロードしてください。

- `TarkovHelper-Setup-*.exe`：インストーラー版（インストール先の選択、デスクトップショートカット、アンインストーラー付き）
- `TarkovHelper-Portable-*.exe`：ポータブル版。ダブルクリックですぐ使えます

> コード署名はしていません。初回起動時に Windows SmartScreen で「Windows によって PC が保護されました」と表示された場合は、「詳細情報 → 実行」をクリックしてください。データ取得のためインターネット接続が必要です。

## 機能

- **ダッシュボード**：タルコフ時間（左/右）、トレーダーの在庫更新タイマー、Goons の最新目撃情報
- **インタラクティブマップ**（tarkov.dev と同等の内容）
  - 脱出地点（PMC / 共通 / Scav。ホバーで脱出エリアを表示、スイッチや必要アイテムの条件付き）、トランジット
  - スポーン：ボス（出現率・顔写真付き）、PMC、Scav、スナイパー Scav
  - タスク：クエストアイテムの出現候補地点と目標エリア。受注中のタスクは専用レイヤーで強調表示
  - ランドマーク：地名、BTR 停留所
  - インタラクト：鍵付きのドア/コンテナ（必要な鍵と電源の要否）、スイッチ（連動先）、据え置き火器
  - 危険エリア：地雷原、スナイパーエリア、迫撃砲エリア（範囲の輪郭付き）
  - すべてのコンテナ（種類別）とルース（アイテムカテゴリ別、アイコン表示）
  - フロア切り替え（別フロアのマーカーは薄く表示、クリックでそのフロアへ移動）、ベクター/衛星写真の切り替え、検索、カーソル座標
- **アイテム価格**：フリマ最安値 / 24 時間平均 / 48 時間の変動、1 マスあたりの価格、トレーダーの買取・販売価格（LL と購入上限付き）、売却のおすすめ、価格推移グラフ（7/30/90 日/全期間、表表示あり）、お気に入り
- **タスク**：名前や目標で検索、トレーダー・マップ・状態・Kappa で絞り込み。詳細ページには目標、必要な鍵、報酬、前後のタスクに加え、EFT Wiki の会話・目標・報酬・攻略（英語原文）を表示
- **タスク進行状況**：ゲームログからタスクの受注/完了/失敗を自動検出（過去のログもすべて読み込み、サーバーごとに記録）。手動での設定も可能で、タスクからマップ上の位置へ直接移動できます
- **BTR ルート予測**（Woods、Streets）：レイドタイマー（開始時刻を自動取得、または残り時間を入力）、BTR の到着/発車を見たらワンクリックで補正し、現在位置と各停留所の到着予定時刻を推定。連続する 2 停留所を補正するとその区間の所要時間を学習し、進行方向も判定します。結果は推定値です
- **スクリーンショットで現在地表示**：ゲーム内でスクリーンショットを撮ると、マップ上に現在地と向きを表示
- **レイド検出**：ゲームログから現在のマップ、サーバー、レイド開始時刻を読み取り自動で反映
- **3 つのサーバー**：PVP / PVE / シーズン。ゲームログに合わせて自動で切り替え
- **多言語対応**：简体中文 / English / 日本語。初回起動時はシステム言語に合わせて選択され、ゲームデータも tarkov.dev の各言語の翻訳を使用
- データソースが利用できないときは前回のキャッシュを表示

## 安全性について

- 読み取るのはスクリーンショットのファイル名とログのテキストだけです。**ゲームのメモリを読んだり、ゲームファイルを変更したりはしません。**
- マップ、座標メタデータ、ゲームデータはすべて実行時に tarkov.dev から取得しており、本プロジェクトには同梱していません。
- Wiki の内容は許可したタグだけで再構成して表示し、元のページをそのまま埋め込むことはありません。

## 開発

[Node.js](https://nodejs.org) 20 以上が必要です。PowerShell でスクリプトの実行がブロックされる場合は、`npm` の代わりに `npm.cmd` を使ってください。

```bash
npm install
npm run dev      # 開発モード
npm run dist     # dist/ にインストーラー版とポータブル版の exe を出力
```

### ディレクトリ構成

```
src/main/         Electron メインプロセス：ウィンドウ、設定、スクリーンショット/ログ監視、タスク進行状況
src/preload/      安全なブリッジ（window.desktop）
src/renderer/     Vue の UI
  src/api/          tarkov.dev のデータ、マップメタデータ、Wiki（キャッシュ付き）
  src/map/          座標変換、フロア判定、レイヤー構築、BTR モデル、アイコン
  src/components/   レイヤーパネル、BTR パネル、価格グラフ
  src/i18n/         UI の翻訳ファイル（zh / en / ja）
  src/views/        ダッシュボード / マップ / 価格 / タスク / タスク詳細 / 設定
```

### ビルド時の注意

初回ビルド時に electron-builder が署名ツール winCodeSign を展開しますが、その中の macOS 用シンボリックリンク 2 つは「開発者モード」を有効にしていない Windows では展開に失敗します。キャッシュに手動で展開すれば回避できます（Windows 向けのビルドではこの 2 ファイルは使いません）。

```
7za x -y %LOCALAPPDATA%\electron-builder\Cache\winCodeSign\<数字>.7z -o%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0
```
